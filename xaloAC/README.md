# XaloAC SMS-Bomber

> ⚠️ **Bu proje yalnızca eğitim, araştırma ve güvenlik farkındalığı amacıyla hazırlanmıştır.**

---

## 📖 Hakkında

**XaloAC SMS-Bomber**, SMS doğrulama servislerinin çalışma mantığını, hız sınırlama (Rate Limiting) mekanizmalarını ve savunma yöntemlerini incelemek amacıyla geliştirilmiş deneysel bir eğitim projesidir.

Bu proje; Python öğrenmek, API yapıları üzerinde çalışmak ve yazılım geliştirme becerilerini geliştirmek amacıyla oluşturulmuştur.

---

## ✨ Özellikler

* Basit terminal arayüzü
* Çoklu servis mimarisi
* Python tabanlı yapı
* Modüler kod tasarımı
* Eğitim ve araştırma odaklı

```bash

cd SMS-Bomber
pip install -r requirements.txt
python main.py
```
